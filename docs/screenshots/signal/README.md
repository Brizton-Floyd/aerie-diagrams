# Signal: before and after

The Lotto sample at 1440 x 900, before (Contour, on `fca11ff`) and after (Signal), in the dark and
the light theme: the overview, an opened container (`#open=engine`), the side panel
(`#sel=engine`), a scenario step (`#play=generate-picks.5`) and presenter mode
(`#present=tour.4`). The files are `before-<theme>-<n>-<state>.png` and
`after-<theme>-<n>-<state>.png`. Contour had no dark default, so its dark pictures are its night map.
